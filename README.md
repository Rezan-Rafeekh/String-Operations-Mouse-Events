## String Operations using Mouse Events

📄 Description

An interactive JavaScript application that performs multiple string operations triggered by mouse events. The program collects a string from the user and executes operations such as substring extraction, string replacement, appending text, and finding the last index of a character when the user hovers over a button.

⚙️ Features

Accepts string input from the user using a prompt box

Executes string operations on mouse hover event

Performs the following operations:

Extracts a substring

Replaces part of the string

Appends additional text

Finds the last index of a specific character

Displays the results dynamically on the web page

🛠️ Technologies Used

HTML5

JavaScript (ES6)

▶️ How to Run

Open the project folder in Visual Studio Code

Open index.html in a browser or using Live Server

Hover over the button to trigger string operations

🎯 Learning Outcomes

Understanding JavaScript string methods

Handling mouse events in JavaScript

Working with prompt-based user input

Dynamic content update using DOM manipulation
